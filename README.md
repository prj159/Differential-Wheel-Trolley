# final.ino 调参指南

## 调试准备

1. 用串口监视器（9600 波特率）连接 Arduino Mega 2560
2. **先调速度环，再调转向，最后调状态切换**
3. 所有实验**从低速开始**（先把 `BASE_VEL` 降到 2~3），跑稳之后再逐步提速

---

## 状态代号对照表

| 状态枚举 | 含义 |
|---------|------|
| `STATE_STRAIGHT` | 直道 |
| `STATE_GENTLE` | 缓弯 |
| `STATE_SHARP` | 急弯 |
| `STATE_EDGE` | 边缘（少量传感器在线） |
| `STATE_RECOVER` | 恢复态（消抖过渡） |
| `STATE_OUT_DEFAULT` | 普通出界 |
| `STATE_OUT_SHARP` | 急弯后出界 |

## 基础参数

### `BASE_VEL`（默认 = 3.0）
默认基础速度。所有状态下的目标速度都以此为基数乘以速度系数。

| 现象 | 调整方向 |
|------|----------|
| 直道跑不稳 | **减小**，先降到 1.5~2.0 跑稳 |
| 直道太慢 | 速度环稳后**逐步加大** |

### `VEL_LIMIT`（默认 = 5.0）
目标速度的上限，防止差速模型分配出过大的单轮速度。

## 第一优先：速度环 PID

使用**增量式 PID**，左右轮共用相同参数。PID 系数由以下三个参数计算得出：

| 参数 | 默认值 | 作用 | 现象与调法 |
|------|--------|------|-----------|
| `P_GAIN` | 15.0 | 比例增益 | 轮子反应慢、跟不上目标 → **加大**；轮子抖动/啸叫 → **减小** |
| `I_TIME` | 70.0 | 积分时间常数（Ti） | 速度一直差一点跟不上 → **减小**（增强积分作用）；速度过冲、振荡 → **加大** |
| `D_TIME` | 15.0 | 微分时间常数（Td） | 速度突变时抑制过冲，一般不动；抖动剧烈可减小 |

**PID 系数计算公式**（增量式）：
```cpp
coeff[0] = P_GAIN * (1 + T/I_TIME + D_TIME/T)
coeff[1] = -P_GAIN * (1 + 2*D_TIME/T)
coeff[2] = P_GAIN * D_TIME/T
```
其中 T = CTRL_PERIOD = 10ms

**左右差异调整**：如果左右轮机械特性不同，可以为左右轮创建独立的 P_GAIN/I_TIME/D_TIME 定义。

## 第二优先：转向 PD 控制

使用 **PD 控制器**（比例+微分）计算转向调整量，并带有微分项低通滤波。

### `STEER_P`（默认 = 0.30）
转向比例系数，决定转弯的响应速度。

| 现象 | 调整方向 |
|------|----------|
| 弯道整体转不过来 | **加大**（0.35→0.40→0.50） |
| 直道上左右摆动（蛇形） | **减小**（0.25→0.20→0.15） |

### `STEER_D`（默认 = 0.20）
转向微分系数，抑制转向过冲和震荡。

| 现象 | 调整方向 |
|------|----------|
| 进弯/出弯震荡明显 | **加大**（0.25→0.30） |
| 转向反应迟钝 | **减小**（0.15→0.10） |

**微分滤波系数**（硬编码）：
```cpp
filteredDerivative = filteredDerivative * 0.6 + rawDerivative * 0.4
```
如果转向高频抖动严重，可以将 0.6 改大（如 0.7 或 0.8）以增强滤波。

## 第三优先：各状态偏差增益

在 `calculateSteeringOutput()` 函数中，不同状态对基础偏差施加不同的增益：

| 状态 | 偏差增益 | 速度系数 | 说明 |
|------|---------|---------|------|
| `STATE_STRAIGHT` | ×1.3 | 1.0 | 直道微调 |
| `STATE_GENTLE` | ×1.8 | 0.8 | 缓弯增强响应，适度降速 |
| `STATE_SHARP` | 8.0（固定） | 0.2 | 急弯满舵，大幅降速 |
| `STATE_EDGE` | ×2.3 | 0.8 | 边缘强化拉回 |
| `STATE_RECOVER` | ×0.8 | 0.8 | 恢复态抑制过冲 |
| `STATE_OUT_*` | 8.0/-8.0 | 0.2 | 出界保持上次方向 |

### 调整建议

| 现象 | 调整位置 |
|------|----------|
| 直道跑偏 | 增大 `STATE_STRAIGHT` 增益（1.3→1.5） |
| 缓弯转不过来 | 增大 `STATE_GENTLE` 增益（1.8→2.2） |
| 缓弯速度太快冲出去 | 减小 `STATE_GENTLE` 速度系数（0.8→0.6） |
| 急弯转不够 | 增大急弯固定值（8.0→10.0） |
| 急弯速度还是太快 | 减小 `STATE_SHARP` 速度系数（0.2→0.15） |
| 出弯后震荡 | 减小 `STATE_RECOVER` 增益（0.8→0.6→0.4） |

## 第四优先：状态判断逻辑

### 直道判断（line 288-292）
```cpp
abs(left_count - right_count) <= 2 &&
active_count <= 3 &&
leftmost_idx != 0 &&
rightmost_idx != 7
```

| 现象 | 调整方向 |
|------|----------|
| 稍微偏一点就判成缓弯 | 放宽条件：`active_count <= 4` |
| 明显偏了还是直道 | 收紧条件：`active_count <= 2` |

### 急弯判断（line 293-298）
触发条件：**最外侧传感器亮（index 0 或 7）且对侧不亮** + **至少 4 个传感器在线**

```cpp
((left_count >= 3 && leftmost_idx == 0 && rightmost_idx != 7) ||
 (right_count >= 3 && rightmost_idx == 7 && leftmost_idx != 0)) &&
active_count >= 4
```

| 现象 | 调整方向 |
|------|----------|
| 急弯判定太迟 | 降低 `active_count >= 4` 为 `>= 3` |
| 缓弯误判为急弯 | 提高 `active_count >= 5` 或 `left_count >= 4` |

### 出界判断（line 244-260）
连续 8 帧（80ms）无传感器在线才判定为出界。

```cpp
if (lostCounter >= 8)
```

| 现象 | 调整方向 |
|------|----------|
| 短暂丢线就判出界 | 增大阈值（8→10→12） |
| 丢线反应太慢 | 减小阈值（8→6→4） |

### 恢复态持续时间（line 323）
从急弯/出界退出后的消抖时间：**8 帧（80ms）**

```cpp
if (recoverTimer >= 8)
```

| 现象 | 调整方向 |
|------|----------|
| 出弯后状态反复跳 | 增大（8→10→12） |
| 出弯后反应迟钝 | 减小（8→6→4） |

## 第五优先：滤波与平滑

### 目标速度低通滤波（line 484-485）
```cpp
leftCtrl.setpoint = leftCtrl.setpoint * 0.37 + prevLeftSetpoint * 0.63
```
- 0.37 = 新值权重
- 0.63 = 旧值权重

**调整建议**：速度变化过于突兀 → 减小新值权重（0.37→0.25）

### 测速低通滤波（line 490, 494）
```cpp
leftSpeed = leftSpeed * 0.6 + rawLeftVel * 0.4
```
- 0.6 = 历史权重
- 0.4 = 新测量权重

**调整建议**：速度值跳变严重 → 增大历史权重（0.6→0.7）

## 历史误差追踪（丢线恢复）

当车辆丢线时，系统会根据**最近 20 帧的历史误差均值**决定转向方向（line 369-385）：

```cpp
float errorHistory[20]
```

| 现象 | 调整方向 |
|------|----------|
| 丢线后找线方向错误 | 增大历史帧数（20→30）以获得更稳定的方向判断 |
| 丢线后转向反应太慢 | 减小历史帧数（20→10）以加快响应 |

---

## 噪点过滤器

当检测到多段不连续的灯条时，只保留与上一帧重叠度最高的段（line 146-208）。

如果出现**误识别邻道线**的情况，检查 line 262-272 的恢复侧过滤逻辑：

```cpp
if (lastValidError > 1.0 && weighted_pos > 3.5)  // 丢线前线在左侧，不应从右侧回来
if (lastValidError < -1.0 && weighted_pos < 3.5) // 丢线前线在右侧，不应从左侧回来
```

阈值 1.0 可以调整（增大 → 更严格过滤，减小 → 更宽松接受）。

## 调试步骤建议

1. **低速测试基础架构**：
   - 设置 `BASE_VEL = 2.0`
   - 只跑直道+缓弯，确认状态判断正确

2. **调试速度环**：
   - 先调 `P_GAIN`，让轮子能基本跟上目标
   - 再调 `I_TIME`，消除稳态误差
   - 最后微调 `D_TIME`（如有抖动）

3. **调试转向**：
   - 调整 `STEER_P` 和 `STEER_D`
   - 调整各状态的偏差增益

4. **调试急弯**：
   - 调整急弯判断条件
   - 调整急弯固定输出值（8.0）和速度系数（0.2）

5. **调试状态切换**：
   - 调整出界判断阈值（lostCounter）
   - 调整恢复态持续时间（recoverTimer）

6. **逐步提速**：
   - 在全部弯道都能稳定通过后，每次增加 0.5~1.0
   - 观察是否需要同步调整转向参数

## 常见问题

### Q1: 左右轮速度不一致
**A**: 如果机械差异较大，可以为左右轮创建独立的 PID 参数：
```cpp
#define L_P_GAIN 15.0
#define R_P_GAIN 14.5  // 右轮稍弱，降低增益
```

### Q2: 编码器方向反了
**A**: 检查 line 488-494 的速度换算，右轮有取反（`-`号），根据实际情况调整。

### Q3: 急弯总是方向判断错误
**A**: 检查 `sharpDirection` 累加逻辑（line 298），确认左右传感器计数（`left_count`/`right_count`）正确。

### Q4: 全黑线停车不工作
**A**: 检查 line 276-284，确认 8 个传感器全部在线时触发 `emergencyStop`。
