# final.ino 调参指南

## 调试准备

1. 用串口监视器（9600 波特率）连接 Arduino Mega 2560，观察输出格式：
   ```
   State: <状态代号>   V_L: <左轮速度>   V_R: <右轮速度>
   ```
2. **先调速度环，再调转向，最后调状态切换。**
3. 所有实验**从低速开始**（先把 `BASE_SPEED` 降到 2~3），跑稳之后再逐步提速。

---

## 状态代号对照表

| 串口输出值 | 状态名 | 含义 |
|-----------|--------|------|
| 0 | `STRAIGHT` | 直道 |
| 1 | `GENTLE_CURVE` | 缓弯 |
| 2 | `SHARP_TURN` | 急弯 |
| 3 | `RIGHT_ANGLE` | 直角弯 |
| 4 | `EDGE` | 边缘 |
| 5 | `RECOVERING` | 恢复态（消抖过渡） |
| 6 | `OUTLINE` | 出界 |

---


## 基础参数

### `BASE_SPEED`（默认 = 6.0）
默认基础速度。所有状态下的目标速度都以此为基数乘以 `speed_factor`。

| 现象 | 调整方向 |
|------|----------|
| 直道跑不稳 | **减小**，先降到 2~3 跑稳 |
| 直道太慢 | 速度环稳后**逐步加大** |

### `MAX_SPEED`（默认 = 10.0）
目标速度的上限，防止差速模型分配出过大的单轮速度。

---

## 第一优先：速度 PID

左轮和右轮各有独立的 PID 参数。先调左轮（`L_*`），再调右轮（`R_*`）。

| 参数 | 默认值 | 作用 | 现象与调法 |
|------|--------|------|-----------|
| `L_Kp` / `R_Kp` | 7.0 | 比例系数 | 轮子反应慢、跟不上目标 → **加大**；轮子抖动/啸叫 → **减小** |
| `L_Ki` / `R_Ki` | 0.14 | 积分系数 | 速度一直差一点跟不上去 → **加大**；速度过冲、来回振荡 → **减小** |
| `L_Kd` / `R_Kd` | 7.0 | 微分系数 | 速度突变时抑制过冲，一般不动；抖动剧烈可减小 |
| `L_INTEGRAL_MAX` / `R_INTEGRAL_MAX` | 80.0 | 积分限幅 | 启动加速慢 → **加大**；松手后车子冲出去 → **减小** |

**左右差异调整**：如果左轮和右轮机械特性不同（齿轮松紧、轮胎摩擦），先让两轮目标速度相同，看串口输出 V_L/V_R 是否一致。不一致的轮子单独调对应的 `L_*` 或 `R_*`。

## 第二优先：转向响应

调完速度环、直道稳定之后，再调转向。

### `STEERING_GAIN`（默认 = 0.8）
偏差→差速的全局缩放。`base_error = (centroid - 3.5) * STEERING_GAIN`。

| 现象 | 调整方向 |
|------|----------|
| 弯道整体转不过来 | **加大**（0.9→1.0→1.2） |
| 直道上左右摆动（蛇形） | **减小**（0.7→0.6→0.5） |

### `computeOutput()` 中各状态增益

| 状态 | 当前增益 | 作用 |
|------|----------|------|
| `STRAIGHT` | ×1.3 | 直道微调 |
| `GENTLE_CURVE` | ×1.6 | 缓弯增强 |
| `EDGE` | ×2.0 | 边缘拉回 |
| `RECOVERING` | ×0.6 | 恢复态抑制过冲 |

| 现象 | 调哪个 |
|------|--------|
| 某个特定弯道转不过来 | 单独加大该状态的增益（如缓弯不够→把 1.6 调到 2.0） |
| 出弯后震荡 | 把 `RECOVERING` 增益减小（如 0.6→0.4） |

## 第三优先：状态判断阈值

观察串口输出的 `State` 值是否在正确时刻切换。

### 直道判断
代码逻辑：只有中间两个灯 L1(index=3) 或 R1(index=4) 亮才算直道。

| 现象 | 可能原因 | 调整 |
|------|----------|------|
| 稍微偏一点就判成缓弯 | 传感器间距确实宽 | 放宽直道条件（在 `judgeState` 中改 `Lmost >= 3 && Rmost <= 4` 为 `Lmost >= 2 && Rmost <= 5`） |
| 明显偏了还是直道 | 阈值太宽 | 收紧条件 |

### 急弯判断（双重判定）
急弯触发条件：**最外侧传感器亮（L4/R4）** 或 **重心变化率 > `SHARP_RATE`**。

#### `SHARP_RATE`（默认 = 1.5）
重心每 10ms 的变化量阈值。约等于 1.5 个传感器间距 / 10ms。

| 现象 | 调整方向 |
|------|----------|
| 缓弯被误判为急弯（满舵太早） | **加大**到 2.0 甚至 2.5 |
| 急弯来不及时判出（进弯太晚） | **减小**到 1.0 甚至 0.8 |

### 直角弯判断
触发条件：`LEDCounter >= 4`（≥4 个传感器同时在线）。

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `RIGHT_ANGLE_OUTPUT` | 3.0 | 直角弯固定差速 |
| `RIGHT_ANGLE_SPEED` | 0.3 | 直角弯速度系数 |

| 现象 | 调整方向 |
|------|----------|
| 不到直角弯就触发（误判） | 提高阈值到 5 甚至 6（`LEDCounter >= 5`） |
| 直角弯不触发 | 降低阈值到 3 |
| 直角弯转得不够猛 | 加大 `RIGHT_ANGLE_OUTPUT`（3.5→4.0） |
| 直角弯冲出去 | 减小 `RIGHT_ANGLE_SPEED`（0.3→0.2） |

## 第四优先：急弯满舵

急弯和直角弯使用固定差速（不做 centroid 比例计算），方向由 `sharp_last_side`（哪侧传感器更多）决定。

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `SHARP_OUTPUT` | 2.4 | 急弯固定差速值 |
| `SHARP_SPEED` | 0.7 | 急弯速度系数 |

| 现象 | 调整方向 |
|------|----------|
| 急弯转不过来 | 加大 `SHARP_OUTPUT`（2.4→3.0） |
| 急弯速度太快冲出去 | 减小 `SHARP_SPEED`（0.7→0.5→0.4） |
| 急弯方向判断错误 | 检查 `sharp_last_side` 累加逻辑，确认左右传感器计数正确 |

---

## 第五优先：出界与恢复

### `OUTLINE_MAX`（默认 = 3.0）
出界时保持的上一次有效偏差的最大值。

### `MAX_OUTLINE_TIME`（默认 = 30，即 30×10ms=300ms）
连续出界超过此时长，紧急停车。

| 现象 | 调整方向 |
|------|----------|
| 短时间冲出赛道就停车 | 加大 `MAX_OUTLINE_TIME` |
| 冲出赛道后不回来也不停车 | 减小 `MAX_OUTLINE_TIME` |

### `TIME_RECOVERING`（默认 = 8，即 8×10ms=80ms）
从急弯/直角弯/出界退出后的消抖过渡时间。

| 现象 | 调整方向 |
|------|----------|
| 出弯后摆动（状态反复跳） | 加大（10→12，更长消抖） |
| 出弯后反应迟钝 | 减小（6→4，更快回到正常） |

---

## 调试步骤建议

1. **关掉满舵**：`SHARP_OUTPUT = 0`，`RIGHT_ANGLE_OUTPUT = 0`，只用 centroid 比例跑直道+缓弯，确认基础架构正确
2. **打开急弯满舵**：调 `SHARP_OUTPUT` 和 `SHARP_SPEED`
3. **打开直角弯**：调 `RIGHT_ANGLE_OUTPUT` 和 `RIGHT_ANGLE_SPEED`
4. **调速率阈值**：如果急弯判得太迟，调低 `SHARP_RATE`
5. **调消抖时间**：根据出弯后是否震荡调 `TIME_RECOVERING`
6. **最后提速**：在全部弯道都能稳定通过后，逐步提高 `BASE_SPEED`
